Adjutant

Adjutant — частный помощник для одного человека (владельца этой страницы). Это не публичный сервис: им не могут пользоваться другие люди, регистрации нет.

Политика конфиденциальности / Privacy Policy

Какие данные. С разрешения владельца Adjutant читает письма в его ящике Gmail, создаёт черновики ответов и переносит рекламные письма в Корзину. Письма не отправляются и не удаляются навсегда.

Где хранятся. Данные обрабатываются на личном сервере владельца. Короткие сведения о письмах (отправитель, тема, краткая суть) хранятся там не дольше 60 дней. Данные не продаются, не передаются третьим лицам и не используются для рекламы. Для пересказа текст письма передаётся в Anthropic Claude API только в момент обработки.

Использование данных Google. Использование и передача информации, полученной через Google API, соответствует Google API Services User Data Policy, включая требования Limited Use.

Отзыв доступа. Доступ отзывается в любой момент: myaccount.google.com/permissions → Adjutant → «Удалить доступ».

English summary: Adjutant is a private, single-user assistant. With the owner's consent it reads the owner's Gmail, creates reply drafts and moves promotional mail to Trash. It never sends or permanently deletes email. Data stays on the owner's private server, is kept no longer than 60 days, is not sold or shared, and is used only to assist the owner. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at myaccount.google.com/permissions.
